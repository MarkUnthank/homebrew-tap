# MarkUnthank Tap

## How do I install these formulae?

`brew install markunthank/tap/<formula>`

Or `brew tap markunthank/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "markunthank/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
