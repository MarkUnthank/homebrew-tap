# Security policy

Report suspected formula, dependency, or distribution vulnerabilities using
[private vulnerability reporting](https://github.com/MarkUnthank/homebrew-tap/security/advisories/new).
For CLI behavior, use [icloud-agent's security policy](https://github.com/MarkUnthank/icloud-agent/blob/main/SECURITY.md).

Include the formula revision, affected release, impact, and a minimal synthetic
reproduction. Never share credentials, account config, or private email/calendar data.
Avoid disclosing exploit details in public issues. Only the latest formula on `main`
is maintained; response and remediation are best effort without an SLA.
